Conseils rapides

  • Gain : amplification. Mets 2.0 si tu veux que tourner la tête de 30° fasse pivoter la vue de 60°. Mets 0 pour neutraliser.
  • Inverser : coche si la vue part dans le mauvais sens (souvent utile pour le yaw avec la caméra arrière).
  • Offset : centre manuel. Permet de corriger une dérive sans relancer la calibration.
  • Zone morte : ignore les petits mouvements en dessous de cette valeur. Utile contre les tremblements résiduels.
